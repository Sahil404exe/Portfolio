About This Project

This is a basic graphical calculator created using Python and Tkinter. It performs common arithmetic operations through a simple interface.

Source Code

import tkinter as tk

def add():
    result = int(number_one.get()) + int(number_two.get())
    output.config(text=result)

window = tk.Tk()
window.title("GUI Calculator")

number_one = tk.Entry(window)
number_one.pack()

number_two = tk.Entry(window)
number_two.pack()

button = tk.Button(window, text="Add", command=add)
button.pack()

output = tk.Label(window, text="")
output.pack()

window.mainloop()
